Drive Check

Upload every file in this folder to the SAME folder on an HTTPS host
(GitHub Pages, Netlify Drop, Cloudflare Pages). index.html must sit beside
manifest.webmanifest, sw.js and the three PNG icons.

Install on a phone
- iPhone: open the link in Safari, tap Share, then Add to Home Screen.
- Android: open the link in Chrome, tap Add to Home Screen when the app
  offers it, or use the browser menu, then Install app.

Then open Drive Check from the new icon, tap Start monitoring and allow location.
